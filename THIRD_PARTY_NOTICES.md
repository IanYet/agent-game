# Third-party software

The portable connector redistributes Node.js (MIT and third-party licenses; <https://nodejs.org/en/about/previous-releases>), the Agent Client Protocol Codex adapter (Apache-2.0; <https://github.com/agentclientprotocol/codex-acp>), the Model Context Protocol TypeScript SDK (MIT; <https://github.com/modelcontextprotocol/typescript-sdk>), Express (MIT; <https://github.com/expressjs/express>), and Zod (MIT; <https://github.com/colinhacks/zod>), together with their bundled dependencies. The website uses React (MIT), Lucide (ISC), DM Sans and Noto Sans SC (SIL Open Font License).

Codex is detected from the user's local installation and is not redistributed. The connector uses that installation's existing ChatGPT sign-in. No OpenAI API key or ChatGPT credential is included in this project or portable package.

License texts for redistributed packages and the runtime are included in the portable package's licenses directory by the packaging script.
