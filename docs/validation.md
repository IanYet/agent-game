## 类型与构建

按改动范围运行 `npm run typecheck`、`npm run build:web` 或 `npm run build:connector`；`npm run build` 可以完成整个项目的类型检查与构建。

改动原生打包时，在对应系统运行 `package:windows` 或 `package:macos`，确认安装包、校验和及构建信息生成成功。发布脚本仍会检查文件完整性和来源，这属于发布流程本身。

## 实际操作

涉及游戏交互时，打开网页检查设置、出牌、暂停继续和回放。涉及连接器时，用实际安装包检查本机连接、模型选择、退出和重新启动。真实推理会使用对应账户额度。

Windows 需要留意不同缩放比例下的窗口与托盘操作；macOS 需要实际确认下载后首次打开、菜单栏、浏览器本地网络权限和退出行为。当前 macOS 包尚未完成 Developer ID 签名与公证。

记录检查结果时写清版本、系统、做过的操作和仍未确认的行为。规则测试通过、构建成功和真实账户对弈是不同结果，只报告本次实际完成的内容。
