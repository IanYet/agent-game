# 游戏桌与记录

[文档目录](../README.md) · [游戏目录](../games/README.md)

## 玩家与模型

每位玩家使用稳定身份；同桌下一局能否调整阵容、继承哪些积分或资源，由各游戏规则决定。最多一位真人，也可全 Agent 观战。查看「玩家与模型」时先只读展示；明确暂停后才能修改，保存或取消后仍保持暂停，主动继续才恢复行动。

玩家卡按「模型名 思考强度」显示连接器返回的实际会话配置，包括程序默认值解析后的结果。会话尚未建立或程序未提供的字段留空；修改选项后，以新会话实际确认的配置更新卡片。

Agent 阅读本局规则、自己的可见局面和记录，自行提交牌、金额、棋步或目标。系统按规则裁定，非法行动返回原因供其修正；真人通过牌桌选牌和操作提示行动。具体操作见各篇[游戏说明](../games/README.md)。

## 开局顺序

新建游戏桌时，可拖拽玩家名单左侧的手柄调整顺序，也可聚焦手柄后用上下方向键移动。玩家身份、名称、模型和思考强度随整位玩家一起移动。名单 1 号首先开始：例如国际象棋执白、富饶之城持初始王冠、花砖物语先选砖、德州首手翻牌前先行动。

保皇仍由皇牌决定登基者，拖拽只调整座位；掼蛋的 1、3 号和 2、4 号分别同队。仅新桌首局使用名单顺序决定先手，「开始下一局」及轮中顺序继续按各游戏规则处理。

## 暂停与继续

Agent 会话依次创建，同桌决策逐个处理。上一条任务结束后，至少等待 3 秒才发送下一条消息；同一阶段需要多位玩家决定时，也按待决策顺序处理。

暂停或断线会取消等待与活动任务。继续时，受中断或失败的玩家会建立新会话；切换模型、刷新或重连后，也会重新同步完整可见局面和记录。正常沿用已有会话时只补发新增记录。

刷新后先回首页，当前桌保留并保持暂停；重新连接不会自动推理。点击继续后才恢复游戏。每次 Agent 决策最多等待 180 秒，超时和限流的处理见[常见问题](troubleshooting.md)。

## 观战与对话

全 Agent 观战时，浏览器可以看到全部手牌，点击 Agent 光球查看该玩家对话；此时没有好奇模式开关。真人参与时，打开好奇模式可查看 Agent 对话，整局结束后才额外翻开余牌。牌库顺序、烧牌等隐藏信息仍不公开，Agent 始终只取得规则允许它查看的信息。

对话面板展示初始化指令、提示、回复、可见思考、工具调用与结果及错误。每条记录可以展开或折叠，顶部「全部展开／全部折叠」同时控制当前玩家的条目和嵌套 JSON；展示筛选不会删改本地存档。

## 保存与导出

浏览器保留当前桌，以及最近 20 局或手的已完成结果和公开日志。游戏状态与 Agent 对话分别保存；对话以压缩格式写入当前浏览器的 localStorage，保留全部条目和正文。原生 Harness 使用临时会话。

已完成记录可回放并导出公开 JSON，国际象棋还可下载 PGN。公开导出保留游戏结果与事件，不包含 Agent 对话；各游戏的回放范围见[游戏目录](../games/README.md)。

浏览器空间不足或存储不可用时会提示保存失败。提示中的「清理本地存储」会直接清除本站保存的存档、对话和偏好设置，并清空历史与旧对话，无需二次确认或刷新页面。当前对局继续运行，后续行动和新对话正常保存；需要保留的记录请先导出。尚未保存的变更在刷新或关闭页面后可能丢失。

项目处于重构期，存档格式不匹配时需要新建游戏，不迁移旧格式。

## 画面效果

页脚可选择跟随系统、减少动态或静态画面，并单独开关鼠标透镜。减少动态和静态画面下，花砖、宝石与棋子的移动直接更新到目标位置。界面最低支持 1920×1080。
