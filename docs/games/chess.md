# 国际象棋

[游戏目录](README.md) · [文档目录](../README.md)

两人标准对弈，白方先行，不计时。走子与计分依据 [FIDE 2023 国际象棋规则](https://handbook.fide.com/chapter/e012023)，合法棋步由 [chess.js 1.4.0](https://jhlywa.github.io/chess.js/) 计算。依赖采用 BSD-2-Clause，网页的「来源与许可」提供完整声明。

新建棋桌时，名单 1 号玩家执白先行，可在创建对局弹窗拖拽名单调整。设置中可决定下一局是否交换黑白。最多一位真人，也可两位 Agent 观战。胜者得 1 分，和棋各得 0.5 分；下一局按玩家身份保留积分和胜和负，新增玩家从零开始。

## 行棋

点选己方棋子，细角框标出当前棋子，细空心圈标出合法落点。选中的落点使用小实心点，再点同一格即可落子。行棋提示显示在真人玩家卡内、提和开关的左侧。兵到末排时在棋盘下方选择后、车、象或马，再点选中的落点完成升变。王车易位通过王的两格移动完成；吃过路兵只在紧接对方兵双步后的那一步有效。不能让自己的王留在将军中，也不能吃王。

落子时，棋子用短暂的滑动过渡从起点移至终点，王车易位的王和车同时移动。回放逐步前进、后退时也有过渡；跳转多个棋步或翻转棋盘时直接切换。选择「减少动态」或「静态画面」，或系统要求减少动态时，棋子立即到位。

棋盘与玩家卡共用镭射纹路、平行炫光和鼠标中心光斑，并额外保留随鼠标移动的银色发散炫光，鼠标划过时轻微倾斜。棋盘下方并排显示玩家卡，真人与 Agent 的宽度为 2:1，两位 Agent 时为 1:1。右侧显示本桌积分和可滚动的牌桌动态；完整棋谱在回放中查看。棋局全部公开；好奇模式只影响 Agent 对话的查看，所有 Agent 观察与工具不会取得别人的对话。

## 结束与和棋

将死立即获胜；无合法棋步且未将军为逼和。王对王、王加单象或单马对王、仅同色格象与王等子力不足局面自动和棋。双马对王、双方有异色格象等仍可能通过合法棋步出现将死的局面，不自动判和。

- 三次重复与双方连续 50 回合无兵移动、无吃子，需要当前行棋方申请。也可先选择一着合法棋步，再申请这着预定棋步将产生的和棋；申请成功后该棋步不实际落子。
- 五次重复、双方连续 75 回合无兵移动且无吃子自动结束。第 75 回合如果将死，优先记为胜负。
- 重复比较包含行棋方、棋子位置、易位权和合法吃过路兵权。丢失易位权后返回原位不算同一局面；不能合法吃过路兵的空目标格不影响重复判定。
- 可随一着棋提出和棋，对方接受、拒绝或直接走子。双方至少各走一步后才能协议和棋。
- 认输按钮常驻在提和开关右侧，仅在自己的决策回合可用，点击直接认输。对方只剩王等不能以任何合法序列将死的已识别子力情况，认输判和。

本桌不使用棋钟、线下触子走子和裁判罚时。程序只接受合法棋步与已经验证成立的和棋申请。复杂封闭兵墙、被迫行棋等非子力不足的死局没有通用证明器，不会自动判和，可由双方协议和棋。

## 记录

每局结束进入公共历史记录。回放可查看开局、每步棋、提和和结算；也可点选棋谱跳到对应局面，或下载 PGN。下一局创建全新的 Agent 会话，保留同桌积分。

领域状态保留初始 FEN、逐步棋谱与带行动的公开事件。恢复时重新应用全部行动，校验棋盘、易位和吃过路兵权、重复次数、提和、计分及结果；不迁移其他存档格式。
