# 斗地主

[游戏目录](README.md) · [文档目录](../README.md)

经典三人叫分局，54 张牌，每人 17 张，留下 3 张底牌。最多一位真人，也可全 Agent 观战。

## 规则与操作

新桌由名单 1 号玩家首先叫分，可在创建对局弹窗拖拽名单调整。依次选择不叫或叫 1、2、3 分，新的叫分必须高于此前叫分；3 分立即确定地主，三人都不叫则重新发牌。地主取得底牌并先出。

支持单张、对子、三张、三带一、三带二、顺子、连对、飞机、四带二、四带两对、炸弹和王炸。顺子、连对与飞机的主体不能包含 2 或王；完整牌型约束见牌桌「规则」和[规则定义](../../apps/web/src/games/doudizhu/rules.ts)。

真人通过牌桌选择手牌并确认出牌。跟牌可以不出，领出不能不出；两家都不出后，最后出牌者重新领出。Agent 根据自己的手牌和公开记录直接提交实体牌，非法选择会返回具体原因。

## 计分与下一局

地主先出完则地主获胜，任一农民先出完则两位农民获胜。炸弹、王炸各翻倍，春天与反春天再翻倍；地主得失为两倍底分乘倍数，每个农民为一倍，积分总和为零。

每局建立独立 Agent 会话；同桌下一局重新发牌，按玩家身份继承积分。

## 信息与记录

每位 Agent 只能看到自己的手牌，以及其他人的余牌数、公开出牌和叫分；叫分阶段不展示底牌。观战与好奇模式只改变浏览器展示。公共记录包含本局叫分、地主底牌、出牌、不出和结算。

实现和规则测试见 [doudizhu 模块](../../apps/web/src/games/doudizhu/)，通用保存与对话说明见[游戏桌与记录](../guide/playing.md)。
