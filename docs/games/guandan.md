# 掼蛋

[游戏目录](README.md) · [文档目录](../README.md)

四人两副牌的常见贡牌版，1、3 座同队，2、4 座同队。新桌首副由名单 1 号玩家先领出，拖拽名单也会改变对家组合。双方从 2 级开始；每副 108 张牌，每人 27 张。

## 出牌与升级

真人在主玩家卡内选牌和确认，支持单张、对子、三张、三带对、五张顺子、三连对、钢板、同点炸弹、同花顺和四王炸。红桃级牌为逢人配，可代替普通牌，不能代替大小王；有多种解释时按声明牌型比较。完整顺牌边界和炸弹层级见牌桌「规则」及[规则定义](../../apps/web/src/games/guandan/rules.ts)。

头游方根据搭档名次升级。双方各自记级，本方打 A 时必须取得头游且搭档非末游才过 A；不设三次失败退级。过 A 后新盘双方从 2 重开，累计盘分保留。

## 贡还与下一副

第二副起按名次贡还牌，支持单贡、双贡和亮王抗贡。贡牌、还牌和抗贡亮王公开；未公开手牌只对本人可见，Agent 不共享搭档私牌。

每副重新建立 Agent 会话，继承双方级数与盘分。本盘尚未过 A 时，保留四位玩家的身份与座位；需要更换阵容时另开新桌。

## 规则来源

牌型、接风、贡还与升级框架参考[东南大学公开比赛规则](https://xxgk.seu.edu.cn/_upload/article/files/44/c8/f455e1d04d2a998e40454931740a/4f853bb4-29b9-45dc-9c56-7627ed4c9726.pdf)，顺牌边界和过 A 参考[2019 年规范征求意见稿](https://www.ttbz.org.cn/upload/file/20191223/6371270213033087899544901.pdf)记录的常见约定。本版明确同点双贡、无小牌还贡与公开余牌数，不使用大学赛事的计时积分制。

实现与规则测试见 [guandan 模块](../../apps/web/src/games/guandan/)，通用观战、记录与保存方式见[游戏桌与记录](../guide/playing.md)。
