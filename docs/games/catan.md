# 卡坦岛

[游戏目录](README.md) · [文档目录](../README.md)

采用 CATAN — The Game **2025 英文第六版基础版，CN3081 v6.250401，3–4 人**。规则核对日期：2026-10-28。

规则来源：

- [CATAN 官方规则册](https://www.catan.com/sites/default/files/2025-03/CN3081%20CATAN%E2%80%93The%20Game%20Rulebook%20secure%20%281%29.pdf)：组件第 3 页，生产和七点第 6 页，交易第 7 页，建造和发展卡第 8–9 页，胜利第 10 页，随机布置第 11–12 页。
- [CATAN 官方基础版 FAQ](https://www.catan.com/faq/basegame)：补充资源短缺、道路中断与并列奖励、骑士时机、港口与强盗、建筑距离和信息可见范围的裁定。

每局随机地形与六段海框。数字盘从随机角按 A–R 逆时针螺旋放置，跳过沙漠。新桌首局由名单 1 号玩家先布置，可在创建对局弹窗拖拽名单调整；同桌下一局由两骰比大小决定先手，同点最高者重新比。初始建筑由玩家选择，正序、逆序各一组；第二座定居点领取相邻资源。本桌采用这套完整随机布置，不提供首次教学用的固定摆法。

完整包含资源生产与短缺、七点弃牌、强盗、道路／定居点／城市、银行与港口交易、玩家协商交易、25 张发展卡、最长道路、最大军队和自己回合达到 10 分的即时胜利。不含 5–6 人扩展、双人变体、友善强盗、海洋或城市与骑士等扩展。

## 操作

进入大厅选择卡坦岛，在玩家名单中配置 3–4 位参与者，最多一位真人，也可全 Agent 观战。规则、模型、暂停继续和下一局由公共框架提供。

真人先选择建造种类，再点击地图上的高亮位置或在位置下拉框中选择，最后确认。可打开「显示坐标」核对顶点、边和地块编号。资源组成、港口最低比例、剩余棋子和发展卡入口放在玩家卡中；发展卡背包使用公共镭射卡面。

行动阶段可任意交错建造、交易和使用发展卡。银行面板按资源填写「我给／换取」，港口比例以自己建筑所在位置计算；拥有 2:1 港口也仍可选择通常的 4:1，或自己已拥有的 3:1。多种资源和同种资源的不同合法比例可一次组合换取。

玩家交易先指定对手或向全桌询价，填写自己的给取数量后报价；也可直接开放协商，邀请别人主动提出交换。被邀请者接受、拒绝或还价，还价的给取从回复者视角填写。全部响应后，当前玩家选择一位成交或结束协商。接受只是意向，确认成交时才同时转移双方资源，并再次核验持有量。每次成交必须包含当前回合玩家，不能赠送、交换同种资源或交易发展卡。

掷骰前可以打出一张以前买到的发展卡。骑士、修路等效果有自己的后续操作；完成后恢复原阶段。每回合最多一张非胜利点发展卡，新买的卡当回合不能用。胜利点自动计入自己的真实分数，自己回合达到 10 分时立即判胜并揭示，无需手动打出。

## Agent 与信息

固定提供 `game_get_state`、`game_rules`、`game_act({revision,action})`。完整中文规则在 `rules.ts`，全部行动字段和 JSON Schema 在 `actions.ts`。Agent 根据地图邻接、自己的手牌和公开局面直接构造行动，不接收合法行动清单。真人和工具调用同一个引擎；拒绝会给出可纠正的原因，原资源、手牌、历史、revision、随机源和决策窗口保持不变。

仅本人观察展示资源组成和未使用发展卡。公开信息包括各人资源与发展卡总数、建筑、道路、已打骑士、奖励和公开得分。弃牌种类仅本人可见，偷取种类仅双方可见。银行展示每种资源有无库存，不公开精确余量，避免通过弃牌前后库存反推出私牌；库存不足会拒绝换取或发明并说明原因。牌库顺序与随机源始终隐藏。纯 Agent 观战可在浏览器查看所有人的手牌，工具和决策提示仍严格使用该 Agent 自己的观察。

弃牌与交易回应可有多个玩家同时待行动，各人的决策窗口不会因为另一人提交而改变。`revision` 仍需使用最新值；若响应过程中其他人更新了状态，先读取状态再重试。

公开回放逐条重建地图、资源总数、公开分和奖励，不提前显示最终建筑，也不翻开未公开发展卡、弃牌或偷取种类。下一局重新生成地图、洗牌并比骰，按稳定玩家身份继承累计胜局。
