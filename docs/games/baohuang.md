# 山东保皇

[游戏目录](README.md) · [文档目录](../README.md)

五人 JJ 标准固定保，四副牌去掉 3、4、5，共 168 张，逆时针行牌。带王冠标记的大王确定皇帝，带交叉双剑标记的小王确定侍卫。

## 身份与操作

皇牌持有人可以登基，也可将皇牌单独交给上家让位；五人都让位后由最初持有人登基。全员准备时，只有侍卫私下选择明保或暗保；皇帝和侍卫是同一人时为独保。

真人在主玩家卡中选牌并确认，也可使用提示或清空选择。支持同点牌、王挂普通牌和纯王混出；跟牌张数相同，并将牌从小到大逐张严格比较。不能出顺子，2 不能配其他普通点数。允许让过，别人接牌后仍可重新上牌；最后出牌者重新领出，已出完时由逆时针下一位未走玩家接风。

## 计分与下一局

普通皇保局按皇帝与侍卫名次合计计算积分；明保翻倍。暗独保、明独保分别按对应争先规则结算，所有结果再乘房间底分，总积分为零。完整名次与分数表见[规则定义](../../apps/web/src/games/baohuang/rules.ts)。

不含进贡、造反、抢独、憋三／憋六、烤牌或断线罚分。下一局重新洗牌确定皇保，按玩家身份继承积分，每位 Agent 建立新会话。

## 信息与来源

暗保身份不在准备记录中公开，打出标记小王或结算时按规则揭晓；中途亮明不会改变开局计分倍数。手牌只对本人可见，Agent 不能询问或读取他人的隐藏身份。

采用 JJ 比赛的[保皇玩法说明](https://www.jj.cn/news/13/20090416112600000245.html)和[积分说明](https://www.jj.cn/news/13/20090519134900000267.html)中的 JJ 标准玩法。实现与规则测试见 [baohuang 模块](../../apps/web/src/games/baohuang/)。
