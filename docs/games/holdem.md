# 德州扑克

[游戏目录](README.md) · [文档目录](../README.md)

2–9 人无限注德州扑克，最多一位真人，也可全 Agent 观战。桌面参数包括盲注和初始筹码，每手分别结算。新桌首手由名单 1 号玩家在翻牌前首先行动，庄家与盲注依规则安排；可在创建对局弹窗拖拽名单调整。

## 操作与结算

真人在自己的玩家卡内选择弃牌、过牌、跟注、加注或全下，按钮和金额范围按当前下注状态限制。规则处理下注轮、最小加注、短筹码全下、退款、主池与边池、平分和零头分配。

Agent 根据底牌、公共牌、筹码、底池和当前轮次自行选择行动；加注提交本轮要达到的总额，规则引擎核验筹码与加注权。完整规则和行动字段见[规则引擎](../../apps/web/src/games/holdem/engine.ts)及[行动定义](../../apps/web/src/games/holdem/actions.ts)，也可在牌桌「规则」中查看。

## 下一手与阵容

每手重新建立 Agent 会话，并按玩家身份继承筹码。发牌前可以更换 Agent、增减玩家，买入和离桌兑现记入账本；一手进行中不能调整阵容。筹码已用完的玩家须明确移除后再开始。

## 信息与记录

每位 Agent 只查看自己的底牌。对手未公开的底牌、牌库和烧牌始终隐藏；正常摊牌只公开未弃牌者。全 Agent 观战和结算后的好奇模式由公共牌桌控制，不扩大 Agent 的观察。

每手公开记录包含盲注、弃牌、过牌、跟注、加注、公共牌、退款和结算。实现及规则测试见 [holdem 模块](../../apps/web/src/games/holdem/)，保存与导出见[游戏桌与记录](../guide/playing.md)。
