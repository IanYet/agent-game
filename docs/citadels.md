# 富饶之城

本模块支持 3–7 人，在玩家名单中新增或移除玩家；最多一位真人，也可以全 Agent 观战。采用 FFG 英文重印版经典基础规则及官方 FAQ v1.2：八身份、66 张非星标建筑牌，八座建筑触发终局。没有加入《暗黑之城》或新版身份。

开局每人四张手牌、两枚金币。初始王冠座位可在游戏参数中指定，请把年龄最大的玩家安排在该座位。三人局依座位选两圈，每人两个身份并共用手牌、金币和城市；4–7 人各选一个身份。每轮先暗弃一张身份，四人再明弃两张、五人明弃一张，国王不会被明弃。七人最后一位从传来的牌和最初暗弃牌中选一张，其余身份保密。

身份按 1–8 叫号，公开后依次行动。每个身份先取两枚金币，或抽两张建筑牌选一张保留，再选择建造及使用技能。税收可在建造前或后一次领取；建筑师额外抽两张，可建三座。手牌、未叫号身份、抽牌选择及魔术师换牌内容不会进入公开记录。被刺杀者跳过整个身份回合，轮末才公开；被刺杀的国王也在轮末继承王冠。

军阀拆除是回合末行动，支付建筑费用减一后立即结束回合；不能拆堡垒、完工城市或未被刺杀的主教城市。墓地拥有者随后有独立的收回决策，不能救回墓地自身，军阀本人不能使用。

牌组含 17 种普通建筑及 11 种紫色建筑。采用旧版实验室弃一牌换一金币、天文台与图书馆组合抽三留二；鬼城在最后一轮建造时不能变色，魔法学校只在税收时变色。大学和龙门各额外两分，拆除费用仍按造价六计算。长城增加其他建筑的拆除费用。完整牌组、各张能力与全部身份时序可在桌面的「规则」查看。

第一位建成八座者触发本轮结束结算，其他身份仍正常行动，建筑师可以继续建到超过八座。计分包括建筑费用、五色奖励、率先及后续完工奖励和特殊建筑奖励。平分先比建筑费用，再比金币，仍相同则共享胜利。下一局重新发牌，保留玩家累计得分和胜局数，初始王冠向下一座传递；可在局间调整阵容。

右侧计分板突出显示本局分数，进行中按当前城区及五色、完工、特殊建筑奖励实时计算，结束后使用正式结算分数；城区数量、累计分数和胜局数放在下方说明。

牌桌顶部将局数、轮次、当前玩家或选角进度合并为一条状态栏，右侧显示王冠与牌库。当前阶段只在操作区说明，不再为玩家数量、当前玩家和重复阶段文字单独占行。

大厅以 🏰 标识本游戏。桌底三维背景使用多色纯色筹码，沿用公共碰撞和鼠标推动。公开回放按事件重建城区，不公开手牌或暗弃身份；好奇模式、光球对话、暂停及继续由公共界面提供。

八张身份卡使用璀璨宝石发展牌相同的公共镭射卡组件和平行炫光，以各身份的 emoji 平铺刻纹。刺客、盗贼、魔术师使用彩色光；国王、主教、商人和军阀分别使用黄、蓝、绿、红色，建筑师使用白色。默认边框不带类别色，静止光点在左上角；选中或当前叫到的身份显示彩色边框，光点移至中央；悬停时显示彩色边框，光照跟随鼠标。身份牌列留出倾斜空间，不使用内部滚动条，卡角不会被裁切。

所有玩家卡内直接展示已建城区，牌多时叠放，可将指针移到卡上查看完整卡面。「已建城区」与「手牌」作为牌列左端的竖排标签，不再另设数量、费用说明行，也不为这些说明预留高度。手牌从左侧排列。建筑卡使用类别色和间距 2px 的同心圆刻纹，炫光与身份卡一样采用公共组件的默认平行炫光，小尺寸卡片的光斑同步收窄；默认边框不带类别色，悬停或选中时才着色。左上角竖排金币表示费用，受光后显色，左下角显示建筑名。紫色特殊建筑的能力在悬停或键盘聚焦时以气泡显示。

真人卡固定占两行，信息区和操作区上下排列，始终为城区、手牌和操作预留空间。所有操作共用固定高度：左侧放候选牌或均匀铺开的动作按钮，右侧说明靠上、确认按钮靠下，候选牌与确认按钮底边对齐。左上角显示当前阶段或须保留与已选择的数量；次要动作按钮默认透明描边，悬停或键盘聚焦时显示主题色描边。二选一时点击另一张会替换选择，确认后才加入手牌，其余放回牌库底。已有手牌保持原样。建造、实验室和置底重抽直接选手牌，选角、刺杀和偷窃点击桌面的身份卡，交换手牌点击目标玩家卡，军阀拆除点击目标城区建筑，再确认。金币收入、税收、铁匠铺、墓地收回和结束回合通过左侧对应按钮执行。不再提供背包、城区详情弹窗或行动下拉框。

真人入座时，其余六位 Agent 最多每行三张；全 Agent 观战每行四张。Agent 优先排满底下一行，再将剩余玩家排在上一行，行内保持座位顺序。Agent 卡只显示手牌数量、金币与已建城区。玩家卡保留公共组件的鼠标倾角与玻璃高光。窄窗口保留公共牌桌、玩家、我的城市和计分动态分区；选择身份或玩家目标时切到对应分区，选中后返回真人操作区。卡内不设置独立滚动条，城区和手牌叠放，操作按钮换行，内容需要更多高度时由页面滚动。

本地开发时打开 `/src/games/citadels/preview.html`，可查看八张城区、四张手牌的展示场景。默认显示操作区的抽牌二选一，可切换建造回合、身份选择，并在「其他操作场景」查看各身份技能、收入、抽三留一或二、墓地、暂停与结算；该页面不连接 Harness，也不读写正式存档。
