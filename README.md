# 同桌 · YOUR MOVE.

和本机的 Agent 一起玩斗地主、无限注德州扑克、山东保皇、国际象棋、花砖物语（Azul）、[富饶之城](docs/citadels.md)、璀璨宝石与四人对家掼蛋。网页负责游戏规则、界面和浏览器存档，本地连接器负责与 Codex、dsh（DeepSeek Harness）、WorkBuddy 通信。

[游戏网站](https://ianyet.github.io/agent-game/) · [连接器下载](https://github.com/IanYet/agent-game/releases/latest) · [源码](https://github.com/IanYet/agent-game)

网页和连接器独立发布。新增游戏只需添加网页模块并发布静态网站；连接器根据模块提供的工具声明和提示词转发请求，不执行网页发来的代码。当前网页版本为 0.5.1，连接器为 0.5.2，桥接协议为 5。本版网页需要 0.5.0 或更新的连接器。

## 开始游戏

1. 安装并登录要使用的 Harness。
2. 下载对应系统和芯片的连接器。Windows 双击 EXE；macOS 解压 ZIP，将「同桌连接器.app」拖入「应用程序」后打开。两端都自带 Node.js。
3. 打开游戏网站。未连接也能浏览游戏；选好游戏后连接本机，允许浏览器访问本地网络，检查检测结果并手动继续。
4. 配置游戏桌，为每位 Agent 选择程序、模型和思考强度。斗地主三人、掼蛋四人、山东保皇五人、国际象棋两人，德州支持 2–9 人、花砖物语支持 2–4 人、富饶之城支持 3–7 人，通过名单新增或移除玩家；最多一位真人，也可全 Agent 观战。未连接时也能先配置，读取模型和开始对局前需连接本机。最后确认开始，已有当前桌时会先要求确认替换。
5. 两端启动后都会显示完整窗口。关闭窗口会继续在 Windows 托盘或 macOS 菜单栏运行，可从图标重新打开；最小化保留在任务栏／程序坞。从窗口、应用菜单或托盘／菜单栏选择「退出连接器」，才会停止本次连接器启动的子进程并释放端口。

| 系统 | 安装包 |
| --- | --- |
| Windows 10 2004（19041）及更新版本，x64，自带 WinUI、.NET 和 Node.js | [同桌连接器 · Windows 64 位](https://github.com/IanYet/agent-game/releases/latest/download/TongZhuo-Connector-Windows-x64.exe) |
| macOS 13.5+，Apple Silicon（M 系列） | [同桌连接器 · macOS Apple Silicon](https://github.com/IanYet/agent-game/releases/latest/download/TongZhuo-Connector-macOS-Apple-Silicon.zip) |
| macOS 13.5+，Intel | [同桌连接器 · macOS Intel](https://github.com/IanYet/agent-game/releases/latest/download/TongZhuo-Connector-macOS-Intel.zip) |

Windows 包尚未做 Authenticode 签名；macOS 包只有 ad-hoc 本地签名，没有 Developer ID 身份签名，也未经过 Apple 公证。ad-hoc 不表示 Apple 已审核或认证。macOS ZIP 根目录附有[首次启动说明](apps/connector/macos/请先阅读.txt)，应用打不开时也可阅读。

macOS 首次打开受阻时，先核对下载来源和校验和；若确认信任且文件未被篡改，先尝试打开一次，再进入「系统设置」→「隐私与安全性」，向下滚动到安全性区域，针对本应用点击「仍要打开」，按要求验证身份，再在警告中点「打开」。受管理的 Mac 可能限制该操作。恶意软件、将损坏电脑或应用已损坏的提示不能当作普通身份提示放行。完整条件见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。无需关闭 Gatekeeper 或删除下载隔离属性。

窗口中的「概览」显示服务与网页状态，「可用程序」说明各程序未就绪的原因，「端口与进程」可查看 PID、路径和 IPv4／IPv6 监听地址。默认端口 3211，遵循 `AGENT_GAME_PORT`。清理前先让原连接器正常退出；强制结束只作用于确认过的单个 PID，未知程序不会被自动停止。清理后重新检测，端口释放后点击「重新检测并启动」。

模型列表来自各 Harness 自己的配置，可见的模型未必有推理权限。连接器复用各自的登录，不要求额外提供 API Key；真实对弈会使用对应账户额度。WorkBuddy 独立 CLI 的登录可能与桌面端不同，若提示 `Authentication required`，需要先在支持 ACP 的官方 CLI 中完成登录。

## 游戏桌与记录

斗地主每局建立独立 Agent 会话，同桌下一局继承积分。德州每手重建会话，并按玩家身份继承筹码；发牌前可以更换 Agent、增减玩家，买入和离桌兑现都会记入账本。一手进行中不能调整阵容。

山东保皇采用 JJ 标准固定保：四副牌去掉 3、4、5，共 168 张，标记大王定皇帝、标记小王定侍卫。支持让位、明保、暗保与独保，逆时针行牌、逐张压牌、下家接风；不含进贡、造反、憋六或烤牌。侍卫在全员同时准备时私下选择明暗，暗保身份在打出标记小王或结算时揭晓。下一局重新洗牌、重建 Agent 会话，按玩家身份继承积分。完整规则和来源可在牌桌的「规则」中查看。

保皇手牌直接显示在主操作卡上，点击选牌后确认出牌，也可使用提示或清空选择。Agent 玩家卡以内嵌小牌展示当前允许查看的手牌。鼠标划过牌组时，当前牌和相邻牌会依次抬起；减少动态或静态画面时关闭这一效果。

璀璨宝石采用 2–4 人基础版完整牌组，支持市场购买、明暗预留、黄金支付、超额归还与贵族来访；15 分触发等轮结束，同分先比较更少的已购发展牌，仍相同共享胜利。下一局重新配置资源、轮换先手，继承累计胜局和总声望。规则与固定牌组来源见[模块说明](apps/web/src/games/splendor/SOURCES.md)。

璀璨宝石玩家卡上的「卡牌背包」可展开发展牌、预留与贵族，按折扣颜色筛选并滚动浏览；选择自己的预留牌后回到主卡支付。对手未公开的预留仍只显示层级，观战与结算后的好奇模式按原有可见范围展示。

花砖物语采用原版标准有色墙规则。点击工厂盘或中央的一种花砖，再选择图案行或地板，确认放砖；铺墙与回收自动按规则结算。墙面、图案行与来源全部公开，袋内顺序隐藏。每局建立独立 Agent 会话，下一局重新洗入 100 片花砖，保留原玩家的累计得分与胜场。已完成记录可以逐步回看选砖、铺墙、扣分与终局奖励。详见[花砖物语规则与操作](apps/web/src/games/azul/README.md)。

掼蛋采用四人两副牌的常见贡牌版，1、3 座同队，2、4 座同队。每副重新建立 Agent 会话，下一副继承双方级数并按名次贡还牌；本盘中途保留四人身份与座位。红桃级牌可配普通牌，支持同花顺、四王炸、接风、双贡与抗贡。双方从 2 打起；本方打 A 时取得头游且搭档非末游才过 A，不设三次不过退级。过 A 后新盘从 2 开始，累计盘分保留。手牌直接显示在主操作卡中，选牌与确认行动都在卡内完成；观战时各玩家卡以内嵌小牌展示允许查看的手牌。牌型与贡还框架参考[东南大学公开比赛规则](https://xxgk.seu.edu.cn/_upload/article/files/44/c8/f455e1d04d2a998e40454931740a/4f853bb4-29b9-45dc-9c56-7627ed4c9726.pdf)，顺牌及过 A 采用明确列在牌桌规则中的常见约定；本版不使用该校赛事的计时积分制。

查看玩家与模型时先只读展示。明确暂停后可修改模型与强度，保存或取消后仍保持暂停；主动继续才恢复行动。刷新后先回首页，突出当前桌并保持暂停，继续时建立新会话；重新连接也不会自动推理。

每次 Agent 决策最多等待 180 秒，包含 Harness 自己的限流重试等待。超时后连接器会撤销本轮行动权限并取消上游任务；取消后 5 秒内仍未结束，会关闭该玩家的本机会话。游戏暂停后，点击继续可重试，已关闭的玩家会话会重新建立。

上游返回 429 或明确的限流错误时，连接器会取消同一程序正在进行的决策，并让这些玩家共享冷却。上游提供 `Retry-After` 或恢复时间时按该时间等待；程序未透传时，保守等待 10 分钟。网页提示剩余时间，冷却期间重复点击继续不会重新请求，结束后需手动继续。Codex ACP 与 App Server 共用冷却，dsh 和 WorkBuddy 各自独立。截止时间保存在本机，重连、重建会话或重启连接器不会清除尚未结束的冷却。

国际象棋固定两人，不计时。点选棋子与合法落点，必要时选择升变棋子，再确认落子。支持王车易位、吃过路兵、将死、逼和、认输与协议和棋；三次重复和 50 回合需要申请，五次重复和 75 回合自动结束。下一局默认交换黑白并保留积分；记录页可逐步回放并下载 PGN。规则来源与判定边界见[国际象棋说明](apps/web/src/games/chess/README.md)。

浏览器保留最近 20 局或手的已完成结果与公开日志，可导出 JSON。每位 Agent 的初始化指令、每轮提示、回复、可见思考、工具调用与结果保存在当前浏览器的 localStorage，原生 Harness 使用临时会话。对话随当前对局和最近 20 条记录保留；浏览器空间不足时会提示保存失败。

全 Agent 观战时可以看到所有手牌，点击 Agent 光球查看该玩家的完整对话，不显示好奇模式开关。真人参与时，可在创建对局的游戏设置、玩家设置或游戏页脚打开「好奇模式」：点击光球查看对话，结算后自动翻开所有余牌，包括德州弃牌者的底牌。好奇模式默认关闭，随时切换，不改变 Agent 能看到的信息。Harness 没有提供的思考内容无法展示。

浏览大厅或记录不结束当前桌。页脚可选择减少动态或静态画面；当前界面面向桌面横屏。

项目处于重构期，不保留旧接口或存档兼容层，也不迁移历史格式。存档版本不匹配时需要新建游戏。

## 本地开发

需要 Node.js 22 或更新版本，推荐 Node.js 24。

```powershell
npm ci
npm run dev
```

网页默认运行在 `http://127.0.0.1:5173`，连接器在 `http://127.0.0.1:3211`。两者直接跨源连接，没有游戏后端或数据库。

```powershell
npm test
npm run typecheck
npm run build
```

自动测试只维护游戏规则，包含牌型、合法行动、回合推进、信息可见范围和结算。界面、连接器和打包行为通过实际使用检查。

在 Windows 安装 .NET 10 SDK 后运行 `npm run package:windows` 生成 EXE；macOS 使用包含 macOS SDK 26 或更新版本的 Xcode 工具链，运行 `npm run package:macos` 生成 ZIP。最低运行系统仍为 macOS 13.5，较新系统的材质与控件外观由 SwiftUI 自动适配。产物写入 `release/`。
