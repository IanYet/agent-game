# 花砖物语 · Azul

采用 Next Move / Plan B 原版标准有色墙，支持 2–4 人，不含灰墙或扩展。规则依据[发行商提供的英文规则书](https://cdn.svc.asmodee.net/production-nextmove/uploads/sites/4/2024/06/EN-Azul-Rules-Next-Move-web.pdf)（版权 2018，2024 年发布的 PDF）。首局随机决定先手；之后按先手标记决定各轮首位。

## 选砖与铺墙

2／3／4 人使用 5／7／9 个工厂盘，每盘补 4 片。五种花砖各 20 片。点一个工厂盘或中央区的一种颜色，会取走该来源的所有同色花砖；工厂盘里的其他砖进入中央。首次从中央拿砖必须带走先手标记，放进地板最左空格；地板已满则放在旁边，仍取得下轮先手。

再点自己的图案行或「全部放地板」，确认后完成回合。图案行从上到下容量为 1–5，已有砖的行只能收同色，墙面同一行已有该颜色也不能再收。每次只能选一条行，溢出落地板；地板最多七格，后续彩砖直接进回收盒。

来源全部取空时，系统从上到下把每条满行的一片砖移到墙面的固定同色格，剩余砖回收。未满行保留。孤立砖得 1 分；有连续相邻砖时分别计算横向、纵向的连续长度，包括新砖。两个方向都相连时相加。

地板依次扣 1、1、2、2、2、3、3 分，先手标记也占一格，最低扣到 0 分。之后清空地板并开新轮。袋空时把回收盒重新洗入；仍不足时按现有数量补盘。

## 终局与下一局

任意玩家完成五格横行时，仍先完成本轮所有人的铺墙和地板结算，再加入奖励：每条横行 2 分、每条竖列 7 分、每种集齐五片的颜色 10 分。最高分获胜；同分比较完整横行数，仍相同则共享胜利。

下一局收回全部花砖重新开始，单局分数归零，按稳定玩家身份保留累计得分和胜场。上一局末轮先手座位顺延，可重新选择 2–4 人阵容。

## 观察与记录

所有玩家的图案行、墙面、地板和市场都公开，袋内顺序和随机状态始终隐藏。Agent 与真人使用同一套规则与合法行动。暂停、继续、好奇模式、光球对话和玩家设置由公共游戏桌提供。

工厂花砖分组围绕中央区呈环形排列，不显示圆盘底座和工厂编号。中央区没有底框，同色花砖逐片并列展示，点击其中一片仍取走中央的全部同色花砖。

真人模式下，真人玩家卡靠最左，Agent 玩家卡区靠右；全 Agent 观战时，最多四张 Agent 卡靠左排列。卡片按内容所需宽度显示，不横向撑满，卡内板面保持居中。真人卡使用适合操作的宽度；Agent 卡按完整单行的姓名、模型、状态和动作记录加宽，不折行、不显示省略号，板面略小于真人卡。

玩家卡直接展示完整的图案行、宫殿墙面和地板。地板横排在第五行下方，与图案行保持相同间距并右对齐，右侧标注「地板行」，各格扣分写在下方。每条图案行填满后，右侧对应墙格会亮起，表示待轮末铺墙。真人选择来源后，点击图案行或地板行，再确认放砖；确认区始终保留位置，切换回合时不改变卡片高度。较小窗口选砖后会切到「我的宫殿」，也可随时返回公共牌桌重新选择来源。

计分板显示轮末已结算的本局总分。玩家卡显示「本轮预估」，每次放砖后按从上到下的顺序计算本轮已填满图案行的铺墙分，再减去地板实际可扣分数；地板最多扣到本局总分为 0，因此本轮预估可以是负数。未满行和终局奖励不提前计入。新轮开始时本轮预估归零，终局后玩家卡显示本局最终得分。

完整公开记录包含每次选砖、中央余砖、铺墙分数、地板扣分和终局奖励；已完成记录可拖动回放进度，也可点具体事件。回放只使用公开事件，不需要袋内顺序。大厅青花纹样、五色瓷砖和先手标记均由模块的原创矢量图案绘制；背景只使用五色花砖，不放先手标记。三维花砖的两面微微隆起，带圆润边缘、光亮釉面和刚体碰撞，静态降级继续使用相同的五色纹样。
