# 勃艮第城堡

2–4 人，采用 2011 年 alea / Ravensburger 原版基础游戏：164 块六角板块、42 件货物、8 种建筑、26 种知识、1–9 号庄园。五个阶段各五轮，每轮每人连续使用两颗骰子。网页运行规则和保存对局，本地连接器转发 Agent 的自然行动。

## 开始与操作

设置中选择经典或进阶开局。经典使用相同的 1 号庄园，起始城堡位于 D4；进阶每人随机获得一张双面庄园，依次选择一面与任意城堡格，选完才公开 A 阶段供应。支持一位真人与 Agent 同玩，也可全部交给 Agent。

真人先选未用骰子和动作，再点选编号仓库的板块、自己的暂存板块、目标庄园格或货物类型。界面显示所需工人数，确认时只支付最少数量。工人按 1↔6 循环调点，已铺知识可以提供免费调整或提高工人效果。白骰只分配本轮货物，不能作行动骰。

暂存区最多三块；满时拿取或购买必须选择丢弃一块旧暂存板块。铺入庄园须颜色一致、骰值可达且邻接已铺板块；同一城市每种建筑限一座，知识 1 可解除限制。点「展开庄园」查看全部格编号、区域大小、完成进度和知识说明。

每回合可以额外花 2 银币买一块黑市板块，知识 6 可扩展到全部七个仓库。购买每回合一次，不耗骰子。两颗骰子用完后仍能购买，最后点「结束回合」。城堡、船或建筑触发后先完成当前立即效果及其连锁，再继续普通行动或购买；建筑的可选效果可放弃。

铺船后选择任意一座编号仓库收货，知识 5 可选相邻两座，6 与 1 相邻。最多持有三种货物；已有类型必须收取，新类型在容量内尽量全部收取，选中类型整堆装入，其他留在原仓。不能丢弃已有货物腾位置。出售也必须整堆售出。

## 得分与下一局

填满同色区域获得区域大小的三角数分，再加当前阶段的 10/8/6/4/2 分。首位与次位覆盖自己庄园某颜色的全部格可拿颜色奖励，分值依人数为 5/6/7 与 2/3/4。动物重计同一印刷牧场内同种动物，不要求彼此相邻。矿山在每个阶段结束时发放银币，E 阶段也发放。

E 阶段第五轮结束后，未售货物每件 1 分、银币每枚 1 分、工人每两名 1 分，再结算已铺知识。暂存板块不计分。同分依次比较庄园空格较多者、最终桥上顺序较后者。下一局重新配置全部板块与资源，按玩家身份继承累计分和胜场。

已完成记录可逐事件回看公共仓库、庄园、骰子、货物、资源与分数。暗供应顺序、未来阶段货物、未使用的初始余货和随机状态不会出现在观察或公开回放中。已售货物只有本人能看实体明细；公开记录仍保留出售时的种类和件数。

长对局的 Agent 对话可能用满浏览器存储。出现空间不足提示时，先保持页面打开，结算后从记录页导出公开 JSON；刷新可能丢失尚未保存的尾部。公开导出保留结果和游戏事件，不包含 Agent 对话。

## Agent 行动

固定提供 `game_get_state`、`game_rules`、`game_act({revision,action})`。Agent 读取完整规则、当前可见局面、庄园与板块资料，自行构造行动，不接收合法行动列表或候选 ID。

| 动作 | 必要选择 |
| --- | --- |
| `setup` | `boardId`、`cellId` |
| `take` | `tileId`、普通行动的 `die`；可选 `workers`、满暂存时的 `discardTileId` |
| `place` | `tileId`、`cellId`、普通行动的 `die`；可选 `workers` |
| `sell` | `goodsType`、普通行动的 `die`；可选 `workers` |
| `workers` | 普通行动的 `die` |
| `buy` | `tileId`、满暂存时的 `discardTileId` |
| `ship` | `depots`；货物超容量时用 `goodsTypes` 指定类型 |
| `decline` / `end_turn` | 放弃可选建筑效果 / 结束本回合 |

`die` 是两颗骰子的下标 0/1。`workers` 表示最多愿意支付多少工人，默认 0，只扣最少所需数量；不得超过余额。立即效果省略 `die`、`workers`。格编号按 A–G 行、每行从左向右编号；板块 ID 使用观察中的实体 ID。非法行动返回具体原因，手牌、资源、记录、版本和当前行动机会全部不变。

## 规则与组件来源

- [2011 原版德文规则书](https://www.brettspiele-report.de/images/d/die_burgen_von_burgund/Spielanleitung_Die_Burgen_von_Burgund.pdf)，[转载说明](https://www.brettspiele-report.de/die-burgen-von-burgund/)标明已获 Ravensburger 授权。采用其阶段、供应、计分、知识和双面庄园规则。
- [Yucata 授权在线版规则](https://www.yucata.de/en/Rules/CastlesOfBurgundy)、[Board Game Arena 游戏页](https://en.boardgamearena.com/gamepanel?game=castlesofburgundy)，用于交叉核对原版组件、知识编号及收货选择。
- 九张庄园依[原版实物板面](https://github.com/mangorine/Burgundy/tree/main/images/boards)逐格核对颜色与印刷骰点，代码独立实现。六角图案、建筑和动物线稿由本模块用 SVG 绘制，没有复制第三方程序或图片素材。
- [动物板块实物照片](https://punchboardgame.blogspot.com/2022/10/castles-of-burgundy-by.html)用于确认每种普通动物数量为 2/2/3/3/4，黑市为 3/4。

本模块明确使用 2011 版：知识 6 仍以银币购买，知识 15 每种已售货物 3 分，知识 26 每块颜色奖励 2 分。不混用 2019 或特别版改动，也不包含扩展、单人或团队玩法。平分按德文原版「空格较多」处理，修正英文原版的反向翻译。
