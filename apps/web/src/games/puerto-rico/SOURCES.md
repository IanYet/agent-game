# 波多黎各

本模块采用 **2002 年经典基础版，3–5 人**。包含六类生产建筑、十二类小紫色建筑和五类大建筑，共 23 种、49 块；支持全部基础角色、角色积累金币、种植、人员安排、建造、生产、贸易、船运和终局计分。不含扩展、后来的双人规则、贵族或工厂与大学价格互换方案。

## 规则来源

- [Rio Grande Games 经典版规则书](https://www.riograndegames.com/wp-content/uploads/2013/02/Puerto-Rico-Rules.pdf)：开局、人数配置、角色流程、23 种建筑和终局计分。三／四／五人局使用 75／100／122 胜利分，工厂 7 金币、大学 8 金币。
- [Rio Grande Games 豪华版规则书](https://www.riograndegames.com/wp-content/uploads/2019/08/Puerto-Rico-Deluxe-Rules.pdf)：用于核对沿用的基础建筑说明，以及工匠额外商品须为本人实际生产过的种类。本模块不采用该版新增内容和后来的五人 126 分配置。
- [BrettspielWelt 授权数字版帮助](https://www.brettspielwelt.de/Hilfe/Anleitungen/PuertoRico/?nation=en)：交叉核对地块、商品和基础建筑数量。最终人数配置与经典版规则书一致。

规则数据写在 [data.ts](data.ts)，完整中文规则由 [rules.ts](rules.ts) 提供，牌桌和 Agent 使用同一份规则。

## 判定与边界

人员船在开局另放 3／4／5 人，不从 55／75／95 人的供应中扣除。市长额外一人只能取自供应；救济院和大学在供应空时可取船员。布置人员时必须尽量占满可用位置，余人才留在圣胡安；已有人员只能在市长阶段重新安排。

旧版总则允许拒绝角色行动，但市长的逐人发放说明没有给出多人拒领的完整示例。为使这处少见情况可执行，本模块明确采用：先按市长顺序声明是否接受船员，再在接受者之间逐个轮发；市长特权独立处理。全体拒领时人员留船，阶段结束只补到应有人数，原来超出的船员保留。这是本模块对未举例边界的确定性约定，不声称是发行商另行发布的裁定。界面、Agent 规则和测试均明确采用这一流程。

生产可全部领取或全部放弃，不能任意减少某一种产量；供应不足按角色顺序领取。工厂只计算实际领到的商品种类，工匠额外一桶在全体生产后领取。

普通船运必须装运所选种类的最大数量；选空船时比较它们可装入的桶数，若都能装下全部商品可任选。同一商品不能占两艘公共船，满船到整个船长阶段结束才卸货。私人码头每阶段最多一次，可选择不用。仓储允许放弃部分或全部商品，小仓库与大仓库合计保护三种商品，另保留一个单桶。

金币以金额记账。银行采用有符号账本，避免实体零钱用尽成为额外终局条件。胜利分用尽后继续记录本轮超出的分数，公开供应显示为零。三种终局条件触发后，仍须完成本轮所有玩家的选角与角色行动。

## 操作与信息范围

真人从公共区域选择角色、地块、建筑、商品或货船，在自己的玩家卡确认行动。市长阶段点击「调整岛屿与城市人员」，在窗口中按岛屿／城市切换并安排人员，返回玩家卡确认。完整岛屿与建筑效果放在详情窗口中。玩家卡内不滚动。

Agent 固定使用 `game_get_state`、`game_rules`、`game_act`，按商品、地块 ID、建筑 key、人员数和货船容量自行构造行动。观察不提供行动清单；错误说明具体原因，拒绝时不改变资源、记录、版本或行动机会。

金币、货物、建筑和人员公开。船运累计分在终局前仅本人可见；观战和好奇模式只改变界面的展示，不扩大 Agent 观察。暗种植园顺序和随机状态始终不进入观察。公开历史可推算的内容不额外伪装为秘密。回放在终局事件前继续隐藏各人的船运累计分，结算事件公开最终明细。

下一局重置本局资源，按玩家身份继承累计分与胜场，轮换初始总督，支持重新配置 3–5 人名单。暂停、继续、玩家与模型设置、已完成记录和导出沿用公共运行时。
