同桌连接器 · macOS 首次启动说明

适用 macOS 13.5 或更新版本。M 系列芯片选择 Apple Silicon 包；Intel 芯片选择 Intel 包。
两个包均自带 Node.js，无需另行安装运行时。Codex、dsh、WorkBuddy 需自行安装并登录。

安装与启动
1. 从项目 GitHub Release 下载与你的芯片匹配的 ZIP，核对来源与旁边的 .sha256 校验和。
2. 解压 ZIP，将「同桌连接器.app」拖到「应用程序」。本说明在 ZIP 根目录，应用打不开时也能阅读。
3. 在「应用程序」中双击「同桌连接器」。正常启动后会显示完整窗口，同时保留顶部菜单栏图标。
4. 回到游戏网页，点击「连接本机」，按浏览器提示允许访问本地网络。

首次打开被 macOS 安全机制阻止时
本包只有 ad-hoc 本地签名，没有 Developer ID 开发者身份签名，也未经过 Apple 公证。
ad-hoc 用于本地代码完整性，并不表示 Apple 已审核、认证应用或验证发布者身份。
以下步骤仅适用于你已核实来源、确认未被篡改，并愿意对这一个应用放行的情况：
1. 先在「应用程序」中尝试打开一次，阅读并关闭系统提示。
2. 打开苹果菜单中的「系统设置」，进入「隐私与安全性」，向下滚动到安全性区域。
3. 找到针对「同桌连接器」被阻止的提示，点击「仍要打开」。按系统要求完成身份验证。
4. 再次出现警告时，确认仍信任这一个应用，再点击「打开」。之后可正常双击启动。

这些步骤遵循 Apple 当前针对 macOS Ventura 及后续系统的逐应用授权说明；文字可能随系统语言与版本略有不同。
若没有该应用的「仍要打开」，可在确认应用位置后再尝试打开一次；受管理的 Mac 可能由管理员限制这些设置。
若提示「将损坏你的电脑」、包含恶意软件、授权已撤销或应用已损坏，不要把它当作普通身份提示放行。
请停止打开，重新核对下载或联系维护者／管理员。此说明不保证所有安全阻挡都能或应当放行。
不需要全局关闭 Gatekeeper，也不需要删除下载隔离属性。
Apple 官方说明：https://support.apple.com/zh-cn/102445

窗口、后台与退出
「概览」显示本机服务与网页连接，「可用程序」显示程序检测结果，「端口与进程」显示实际监听者。
关闭窗口会继续后台运行，最小化留在程序坞。从菜单栏「打开连接器」或点击程序坞图标可恢复窗口。
「停止服务」结束本次连接器启动的 Agent 会话并释放端口，窗口仍可使用。
菜单栏或应用菜单中的「退出连接器」（⌘Q）才会完整退出，同时清理本次连接器的子进程。
应用「设置」（⌘,）可选择打开应用时是否自动启动本机服务，外观跟随系统。

端口被占用
默认端口 3211，遵循 AGENT_GAME_PORT。先点击「重新检测」查看 PID、程序路径和 IPv4／IPv6 监听地址。
优先请求连接器正常退出；旧版可从原菜单栏退出。其他程序请先保存任务并从它自己的界面退出。
强制结束必须逐个确认具体 PID 和影响。未知程序不会被自动停止；没有权限、身份变化或释放失败时会显示原因。
操作后重新检测，端口释放后点击「重新检测并启动」。若又出现占用，请核对新的列表。

数据与自定义 connector.config.json：~/Library/Application Support/AgentArcade/
日志：~/Library/Logs/AgentArcade/connector.log
AGENT_GAME_CONFIG 可指定其他配置文件；AGENT_GAME_DATA_DIR 可指定数据目录（日志也存入该目录的 logs）。
下载旁的 .build.json 记录源提交、芯片、运行时、校验和与签名状态。
